# 🕵️ Network Sniffer (Python)

A simple network sniffer built using Python and Scapy that captures and analyzes live network packets.

---

## 🚀 Features
- Capture live network packets
- Display source and destination IP
- Show TCP ports
- Extract raw payload data

---

## 🧰 Technologies Used
- Python
- Scapy

---
